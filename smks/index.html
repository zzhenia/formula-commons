The five tools

01 · inbox sweeper

Files unprocessed daily notes into the notes they belong to, drafts the links, leaves you a five-minute review list.

02 · duplicate merger

Finds the notes you wrote twice, proposes one merged note, never deletes anything.

03 · vault map

A home page that rebuilds itself from what’s actually in your vault, orphans included.

04 · meeting intake

A photo of a handwritten page becomes a filed, linked meeting note.

05 · weekly review runner

Runs the other four in one command and writes the review note; you answer three questions.

Safe by design

  • Saved before every run
  • Plan shown before every change
  • Nothing is ever deleted

The vault stays yours; git keeps every version.

What you get

  • The System Brief — one page about your notes, filled in before you open the terminal
  • The Vault Memory File (AGENTS.md) — so your assistant knows your vault’s rules every session, whichever assistant it is
  • Five recipes — exact prompt sequences, copy and paste, one tool each
  • The Safety card — backup in three commands, dry-run rule, restore in one command
  • Five videos (~29 min) building every tool on a real, messy vault, mistakes included
  • A one-page operating manual

What you need

  • Your notes as markdown files — Obsidian, Logseq, iA Writer, or a plain folder
  • Git on your machine — free; GitHub is optional
  • One terminal AI assistant — Claude Code and Codex CLI need their paid plans (Claude Pro, ChatGPT Plus); Gemini CLI is free with a Google account; Cursor has a free tier. Install guide included.

For you if

  • Your system mostly works, and there’s a backlog you feel bad about

Who made it

I finished my PhD in four years instead of six, and for most of those years the real project underneath was how to capture and process knowledge without drowning in it.

Only afterwards did I find the Second Brain and Obsidian communities on Reddit, and I was surprised: with so many tools available, people were describing the same pains I’d worked through alone.

So I went back to the problem with what’s changed since: AI tools that can work inside a notes folder. SMKS is the result, an Obsidian-compatible vault template that stays open to whatever AI tool you use next.

Questions

Do I need to code?
No. You paste prompts; the assistant writes the tools.
Which AI do I need?
Any terminal assistant: Claude Code, Codex CLI, Gemini CLI, Cursor.
What if I don’t have a paid AI plan?
Gemini CLI is free with a Google account; a local model via Ollama also works, weaker on merging and handwriting.
Will it touch my existing notes?
Only through the tools, after showing a plan, and never deleting; every run is one command to undo.
Does it work without GitHub?
Yes. Git on your machine is enough; GitHub is optional backup.
